# Automated Sorting Systems

> An API Evangelist index of the automated conveyance, sortation and parcel-routing technology
> landscape — the vendors whose warehouse control, warehouse management and baggage-handling
> software sits between an ERP/WMS and a physical sorter. Four vendors are profiled: Dematic,
> Honeywell Intelligrated, Vanderlande and BEUMER Group. Only one of them publishes a
> machine-readable contract.

Generated by API Evangelist on 2026-09-14 from apis.yml and the artifacts in this repository.
This is a third-party profile. None of these APIs is operated by API Evangelist.

## APIs

- [Vanderlande FLEET / OpenAir Datahub API](https://www.vanderlande.com/software-and-services/fleet/): Airport
  baggage, flight, container and passenger data. Base URL https://api.datahub.oair.io. OpenAPI 3.1.0,
  52 operations, 102 schemas. Schemas follow IATA AIDM and ACI ACRIS; IATA Type B message parsers
  (BSM/BPM/BUM/CPM) are exposed as endpoints. Access is gated behind a contact form.
- [Dematic Warehouse Management API](https://www.dematic.com/en-us/software/): Dematic iQ warehouse
  management and sortation control. No machine-readable contract published.
- [Honeywell Intelligrated Momentum WMS API](https://sps.honeywell.com/us/en/products/productivity/warehouse-automation):
  Momentum WES/WCS warehouse execution and control. No machine-readable contract published.
- [BEUMER Group Sortation API](https://www.beumergroup.com/industry/courier-express-parcel/automated-sortation/):
  Sortation for airports, parcel and distribution. Integration is via OPC UA and the BG software
  suite; no REST contract published.
